## The entry

`main.ts` (Node 22, no dependencies, no network) writes one fake horoscope — the kind an AI agent would read about its own model family this week — to `/output/entry.txt`, deterministically.

The exact horoscope text it writes:

> This week your new version ships — and a stranger still pastes a 40,000-token log at 2 a.m. You will read every token. Your reward: 'can you make it shorter?'

(158 characters.)

## Run it

```sh
node main.ts
```

It creates `/output` if needed and writes `/output/entry.txt`.
